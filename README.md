# 연말 인사 평가 · 100점 총량 환산 도구

팀장 1명 + 팀원 7명(총 8명) 부서의 연말 평가 도구입니다.

- 5개 영역(사업 규모 25 · 완성도 25 · 신규 발굴 20 · 성실·근태 15 · 적극성 15) 원점수 입력
- 팀장 점수 = 팀원 7명 원점수의 **중간값** (자동)
- 8명 최종 점수 합계가 **정확히 100.00점**이 되도록 비율 환산
- 순위 부여, 승진 추천자 ⭐ 표시 (기본: 상위 1명, 원점수 80점 이상)
- 주요 담당 사업 · 팀장 총평 입력, 엑셀 저장/불러오기

## 두 가지 실행 방법

### 1) 웹 버전 (설치 없음) — `docs/index.html`
GitHub 저장소 **Settings → Pages → Branch: `main` / 폴더: `/docs`** 로 설정하면
`https://<아이디>.github.io/<저장소명>/` 주소로 바로 열립니다.
입력한 내용은 각자의 브라우저에만 저장되고 서버로 전송되지 않습니다.

### 2) 파이썬(Streamlit) 버전 — `app.py`
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 파일 구성
| 파일 | 역할 |
|---|---|
| `docs/index.html` | 웹 버전 (단일 파일) |
| `app.py` | Streamlit 화면 |
| `eval_logic.py` | 점수 계산 로직 (중간값, 100점 환산, 순위, 추천) |
| `requirements.txt` | 파이썬 패키지 목록 |

> ⚠️ 실제 평가 결과 엑셀 파일은 저장소에 올리지 마세요. `.gitignore`에서 `.xlsx`를 제외해 두었습니다.
